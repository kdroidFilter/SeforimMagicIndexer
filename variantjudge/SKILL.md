# Resume the Hebrew variant semantic-judge

You are continuing in-progress work on the **lexical-variant judge** for the Seforim
full-text-search database. This skill restores the state so you can resume without
re-discovering anything.

## What this system is

`lexical.db` holds, per Hebrew **surface** form, a **base** lemma and a list of
candidate **variants** (orthographic / morphological / Aramaic-cognate forms) used to
expand full-text search over rabbinic literature (Mishna, Talmud Bavli & Yerushalmi,
Midrash, Rishonim, Acharonim, responsa).

Three models touch the variants:
1. **Gemini** — generates candidate variants (upstream, not in this repo).
2. **MiniMax** (`MainJudgeVariants` Kotlin pipeline) — hard-deletes variants it judges
   hallucinated, logging each deletion to `variant_removal_log`.
3. **(you)** — the **semantic judge / QA**: independently review MiniMax's
   removals, catch false removals, and run the batch purge+enrich pipeline.

## How to resume

First read `variant_audit_notes.md` (tail) and `.audit_cursor` to confirm the live
state, then pick the mode:

### Mode A — QA audit loop (read-only, the default "continue")
This is the cursor-tracked task; "where it stopped" = the cursor above.
1. Follow `.claude/commands/audit-variants.md` exactly.
2. Resolve the DB, count `variant_removal_log WHERE removed_at > <cursor>`.
   If 0 → append a one-line "no activity" entry and stop without moving the cursor.
3. Sample ≤20 rows across the window, judge each legit ✅ vs false ⚠️ using the
   linguistic rules in `claude-batch/subagent_prompt.md` (HR1–HR6, the 8 legitimate-variant classes).
4. Append a dated section (template in the command), update the cursor to
   `MAX(removed_at)` of the **full window** (not just the sample).
5. **Read-only on the DB** — never modify `surface_variant` / `variant_removal_log`,
   never re-insert; only log recommendations for a human.

### Mode B — batch purge + enrich (writes to DB)
Use when asked to actually clean/enrich, not just audit.
1. `python3 claude-batch/pull_batch.py <db> [limit=50] [offset=0]` → unjudged surfaces JSON.
2. Optionally `python3 claude-batch/split_batch.py <input.json> <prefix> <chunk>` to chunk.
3. Judge each chunk with the **`claude-batch/subagent_prompt.md`** system prompt
   (dual task: `false_variants` to delete + `additions` to insert). Be as conservative
   when enriching as when purging — when in doubt, leave it alone.
4. `python3 claude-batch/apply_verdicts.py <db> <verdict_file>` applies deletions +
   additions, logs to `variant_removal_log` / `variant_addition_log`, marks surfaces
   judged. It enforces HR1/HR2 (refuses to touch `variant == base|surface`).
5. Back up `lexical.db` before a large apply; this mode hard-deletes.
